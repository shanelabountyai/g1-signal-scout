## Things to know before continuing

- `n8n/build.py` generates `docs/duplication-log.md` (both halves). Do not edit the log by hand; edit the generator. Running `build.py` also rewrites `n8n/g1-signal-scout.json`, and the Gmail credential lookup reads the owner's `~/.n8n` database — run it only on the owner's Mac.
- `tests/test_prompts.py` pins G1·C's prompts to `n8n/prompts.py`. Change an instruction in `n8n/prompts.py`, then copy it; the test tells you where.
- State files: `SCOUT_DB_PATH` (seen items, default `~/.g1-signal-scout/scout.sqlite`) and `G0_DB_PATH` (the layer, default `~/.g0-shared-layer/layer.sqlite`). Deleting the first makes the next run re-pick this week's items.
- `--judge claude` turns on G0's model judge for the evaluations: logged and capped like every other call, but it adds cost G1·B never paid, so keep it off for the comparison run.
